Darwin 是一个基于 LLM 的 GitHub AI Agent 项目，旨在通过自然语言提示自动化处理修复 Issue、编写文档和审查 PR 等开发任务。该项目强调低门槛使用和项目级 API 定制，目前处于 Alpha 阶段并寻求测试反馈。HN 社区对其在 DevOps 场景的落地表现出较高关注与讨论热情。
