## 综合总结
本文介绍了在 Transformers.js 中实验性支持 Cross-Origin Storage API 的工作。针对浏览器端运行大模型时跨域加载与缓存隔离的痛点，探讨了如何利用该新 Web API 实现不同源之间安全共享模型权重与缓存，从而优化加载性能并减少带宽消耗。该实验为前端 AI 工程实践提供了前瞻性指引，尽管目前 API 兼容性尚处早期，但极具探索价值。
