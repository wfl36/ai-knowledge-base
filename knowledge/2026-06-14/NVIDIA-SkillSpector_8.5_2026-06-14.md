## 项目描述
Security scanner for AI agent skills. Detect vulnerabilities, malicious patterns, and security risks.

## 综合总结
NVIDIA 推出的 SkillSpector 是一款专为 AI Agent 技能设计的安全扫描工具，旨在检测漏洞、恶意模式及安全风险。该项目精准切中了 Agent 生态中工具层安全的痛点，技术针对性强，实用价值极高，且凭借 NVIDIA 的背书和亮眼的社区数据，有望成为保障 AI Agent 安全部署的关键基础设施。

### 技术先进性 (评分: 8.0/10)
SkillSpector 聚焦于 AI Agent 技能的安全扫描，填补了 Agent 生态中工具层安全审计的空白。其技术架构结合了静态分析与恶意模式识别，针对 LLM 调用外部工具可能引发的安全风险（如提示注入、权限越权等）进行了专门优化，体现了 NVIDIA 在 AI 基础设施安全领域的深入思考与前瞻性布局。
