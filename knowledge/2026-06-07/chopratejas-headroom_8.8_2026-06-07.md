## 项目描述
Compress tool outputs, logs, files, and RAG chunks before they reach the LLM. 60-95% fewer tokens, same answers. Library, proxy, MCP server.

## 综合总结
Headroom 是一款专为 LLM 应用设计的上下文压缩工具，能够在保留核心语义的前提下将日志、文件及 RAG 数据块的 Token 消耗降低 60-95%。项目支持库调用、代理和 MCP 服务器等多种集成方式，直击 LLM 开发中的成本与上下文长度痛点，工程化程度高且即插即用。凭借其卓越的实用价值，项目已收获超1.6万 Star，成为构建高效 LLM 应用不可或缺的基础设施。
