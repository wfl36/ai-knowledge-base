## 项目描述
A library of Agent Skills designed to work with the Stitch MCP server. Each skill follows the Agent Skills open standard, for compatibility with coding agents such as Antigravity, Gemini CLI, Claude Code, Cursor.

## 综合总结
Stitch Skills 是由 Google Labs 推出的一个基于 MCP 服务器的 Agent 技能库，遵循 Agent Skills 开放标准。该项目旨在为 Gemini CLI、Claude Code、Cursor 等主流编码代理提供标准化、可复用的技能扩展，有效解决了不同 AI 编码工具之间能力互操作性的痛点。凭借其良好的生态兼容性和模块化设计，项目在开发者社区获得了显著关注，是推动 AI Agent 工具生态标准化的重要实践。
