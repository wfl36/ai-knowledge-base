## 项目描述
Security scanner for AI agent skills. Detect vulnerabilities, malicious patterns, and security risks.

## 综合总结
NVIDIA/SkillSpector 是一款专注于 AI Agent 技能安全的扫描工具，能够有效检测漏洞、恶意模式及潜在安全风险。该项目直击当前 Agent 生态中第三方技能带来的安全隐患痛点，具有极高的实际应用价值，为构建安全可靠的 Agent 系统提供了关键基础设施。虽然在底层算法上未构成颠覆性突破，但其在 Agent 安全这一新兴赛道的先发优势和 NVIDIA 的工程实力使其成为值得关注的重要项目。
