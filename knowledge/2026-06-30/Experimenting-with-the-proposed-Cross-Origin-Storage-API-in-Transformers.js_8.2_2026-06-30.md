## 综合总结
本文探讨了在 Transformers.js 中实验性地使用提议的 Cross-Origin Storage API。该 API 旨在打破浏览器同源策略对存储的限制，允许跨源共享大模型缓存数据，从而解决 Web AI 应用中模型重复下载和存储空间浪费的痛点，显著提升端侧模型的加载速度与用户体验。
