## 项目描述
A library of Agent Skills designed to work with the Stitch MCP server. Each skill follows the Agent Skills open standard, for compatibility with coding agents such as Antigravity, Gemini CLI, Claude Code, Cursor.

## 综合总结
Stitch Skills 是 Google Labs 推出的 Agent 技能库，专为 Stitch MCP 服务器设计并遵循开放标准。它兼容 Gemini CLI、Claude Code、Cursor 等主流编码代理，极大提升了 AI 编码工具的互操作性与功能扩展性。项目在生态整合与实用性上表现优异，为开发者提供了高质量、开箱即用的 AI 编码技能基础设施，是 AI Agent 标准化进程中的重要实践。
