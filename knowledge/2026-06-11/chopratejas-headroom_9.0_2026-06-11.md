## 项目描述
Compress tool outputs, logs, files, and RAG chunks before they reach the LLM. 60-95% fewer tokens, same answers. Library, proxy, MCP server.

## 综合总结
Headroom 是一款专为 LLM 应用设计的上下文压缩中间件，通过先进的语义压缩技术将 Token 消耗降低 60-95%，同时保证输出质量不变。它以 Library、Proxy 和 MCP Server 三种灵活方式接入，完美解决 RAG 和 Agent 场景下的成本与上下文长度痛点。凭借极高的实用价值和优秀的工程架构，该项目在社区中获得了极高的关注与认可，是当前 LLM 应用开发不可或缺的基础设施级项目。
