## 项目描述
Multi-platform SDK for integrating GitHub Copilot Agent into apps and services

## 综合总结
GitHub 官方推出的 Copilot Agent 多平台集成 SDK，旨在帮助开发者轻松将 Copilot 能力嵌入各类应用与服务。项目实用性极强，社区关注度高且由官方背书，是构建 AI 编程生态和开发者工具的重要基础设施。
