## 项目描述
A library of Agent Skills designed to work with the Stitch MCP server. Each skill follows the Agent Skills open standard, for compatibility with coding agents such as Antigravity, Gemini CLI, Claude Code, Cursor.

## 综合总结
Stitch Skills 是由 Google Labs 推出的一个 Agent 技能库，专为 Stitch MCP 服务器设计。该项目遵循 Agent Skills 开放标准，能够无缝兼容 Claude Code、Cursor、Gemini CLI 等主流编码代理。它通过提供现成的高质量技能，极大地降低了 AI 编码代理的开发与扩展门槛，推动了 MCP 协议生态的标准化和实用化。凭借 Google 的背书和极高的 GitHub 关注度，该项目在 AI Agent 工具链中具有显著的生态整合价值与实用意义。
